# QA API Autotests

Учебный проект с API автотестами на Python, pytest и requests.

Цель проекта - собрать понятный каркас, который можно показать и обсудить на собеседовании на QA Automation.

## Что здесь есть

- `conftest.py` - общие pytest фикстуры и тестовый API сервер.
- `api_clients/` - низкоуровневый HTTP клиент.
- `pages/` - Page Object слой для API.
- `tests/` - тесты.
- `.github/workflows/api-tests.yml` - CI для GitHub Actions.
- `docs/python_notes.md` - короткие заметки по Python простым языком.

## Как запустить локально

```bash
python -m venv .venv
python -m pip install -r requirements.txt
pytest
```

## Как устроен проект простыми словами

Фикстура - это подготовка для теста. Например: создать API клиент, запустить тестовый сервер или вернуть готовый объект для работы с пользователями.

Page Object - это слой, который прячет детали запросов. Тест говорит: "получи пользователя" или "создай пользователя", а не собирает URL и JSON каждый раз руками.

HTTP клиент - это общий класс, который умеет отправлять запросы. Сейчас он знает, как делать `GET` и `POST`.

Тест - это проверка ожидания. Например: если мы запросили существующего пользователя, сервер должен вернуть статус `200` и данные этого пользователя.

## Что уже проверяем

- получение списка пользователей;
- получение существующего пользователя;
- создание пользователя;
- получение ошибки `404`, если пользователя нет.
